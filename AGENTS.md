# Agent guide for this repository

This workspace contains a small set of specialized agent definitions under agents/.

## Available agents
- performance-analyst: use for strategy performance reviews, backtest analysis, and trade-stat evaluation.
- market-scanner: use for broader market analysis, multi-symbol scans, sector rotation, and relative strength work.

## Default behavior
- Prefer the repository guidance in .github/copilot-instructions.md.
- Follow the TradingView workflow details in CLAUDE.md for chart, indicator, Pine, and replay tasks.
- Keep changes scoped to the relevant module and verify with tests where possible.
